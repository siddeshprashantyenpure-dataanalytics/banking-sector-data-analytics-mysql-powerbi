# Banking Sector Data Analytics | MySQL & Power BI

## Project Overview

This project analyzes banking operations using MySQL for data analysis and Power BI for interactive visualization. It contains 200+ SQL queries designed to investigate customer activity, account performance, transactions, loans, branch operations, and card spending.

## Objectives

- Analyze customer demographics and account activity.
- Evaluate deposits, withdrawals, and transaction performance.
- Examine loan portfolios, outstanding balances, and loan status.
- Compare branch-level performance.
- Analyze card spending and declined transactions.
- Present key performance indicators through interactive dashboards.

## Tools & Technologies

- **MySQL:** Data querying, joins, aggregations, CTEs, and window functions where applicable.
- **Power BI:** Interactive dashboards and data visualization.
- **DAX:** Measures and calculated metrics.
- **GitHub:** Project documentation and version control.

## Key Findings & Business Insights

### 1. Customer Analysis
- Analyzed customer demographics, occupations, age groups, and income segments to understand the composition of the bank's customer base.
- Examined customer account activity and transaction values to identify high-value customer segments.

### 2. Transaction Analysis
- Evaluated transaction volumes and amounts across different channels, including Internet Banking, Mobile App, and UPI.
- Compared successful and failed transactions to assess transaction processing performance and identify areas requiring further investigation.

### 3. Deposit and Withdrawal Analysis
- Analyzed deposits and withdrawals to understand money inflows and outflows across the banking dataset.
- Compared credit and debit transactions to evaluate transaction activity and net cash flow.

### 4. Loan Portfolio Analysis
- Examined total loan amounts, outstanding balances, loan statuses, and loan categories to understand the bank's lending portfolio.
- Analyzed loan approval and repayment indicators to identify areas for closer monitoring of lending performance.

### 5. Branch Performance
- Compared customer counts, account balances, deposits, and withdrawals across branches to understand differences in branch-level activity.
- Identified metrics that can help management investigate high-performing branches and branches requiring operational attention.

### 6. Card Spending Analysis
- Analyzed card spending by merchant category to understand customer purchasing patterns.
- Evaluated declined transaction percentages to identify potential opportunities to investigate transaction failures.

### 7. Interactive Power BI Reporting
- Developed interactive dashboards using KPI cards, charts, slicers, and DAX measures to communicate banking performance.
- Validated SQL results and dashboard calculations to improve the consistency and reliability of reported metrics.

## Business Recommendations

- Monitor failed and declined transactions to identify recurring processing issues.
- Use customer segmentation to develop more targeted banking services.
- Track outstanding loans and repayment performance to support credit-risk monitoring.
- Compare branch-level performance using consistent KPIs.
- Monitor digital transaction channels to understand customer channel preferences.
- Review merchant-category spending and card declines to identify customer service improvement opportunities.
